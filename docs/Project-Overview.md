# Smart Farming AI Platform

The Smart Farming AI Platform is an AI-powered agricultural solution that helps farmers make better decisions using crop recommendation, weather prediction, soil analysis, market price analysis and Gemini AI.

## Features

- AI Crop Recommendation
- Weather Forecast
- Soil Analysis
- Gemini AI Chatbot
- Farmer Dashboard
- Market Analysis

## Future Scope

- IoT Integration
- Drone Monitoring
- Satellite Analysis
- Voice Assistant
