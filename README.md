# 🌱 Smart Farming AI Platform

An AI-powered Smart Farming Platform that helps farmers make better agricultural decisions using Artificial Intelligence, Machine Learning, Weather Forecasting, Market Price Analysis, and Gemini AI.

---

## 🚀 Features

- 🌾 AI Crop Recommendation
- 🌦️ Live Weather Forecast
- 📈 Market Price Analysis
- 🤖 Gemini AI Farming Assistant
- 🧪 Soil Analysis
- 📊 Smart Dashboard
- 📱 Responsive UI
- 🔐 Secure Authentication

---

## 🛠 Tech Stack

- React.js
- Tailwind CSS
- Python
- Flask
- Machine Learning
- Gemini API
- Weather API
- Chart.js
